# 🌤 Weather App

This is a simple and interactive Weather App built using HTML, CSS, and JavaScript. It allows users to select a city and view real-time weather information fetched from an API.

## 🚀 Features

- Select a city from a dropdown menu
- Fetch real-time weather data from API
- Display:
  - Temperature
  - Feels like temperature
  - Humidity
  - Wind speed and gust
  - Weather condition
  - City name
- Weather icon display
- Error handling for failed requests

## 🛠 Technologies Used

- HTML
- CSS
- JavaScript (ES6)
- Fetch API

## 📡 API Used

FreeCodeCamp Weather API:
https://weather-proxy.freecodecamp.rocks/

## ▶️ How to Run

1. Clone this repository
2. Open `index.html` in your browser
3. Select a city and click "Get Weather"
